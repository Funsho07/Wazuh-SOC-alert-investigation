# Wazuh-SOC-alert-investigation
# SOC Alert Detection & Investigation with Wazuh

## Objectives
- Simulate security-related activities on an Ubuntu endpoint.
- Detect and investigate security events using Wazuh.
- Understand how endpoint activity maps to security alerts and MITRE ATT&CK techniques.

## Goals
- Generate three security events involving user account creation, privileged command execution, and system file modification.
- Investigate the resulting alerts in the Wazuh Dashboard.
- Document alert severity, rule IDs, event details, and security implications.

## Tools Used
- **Wazuh 4.14.7** — Security monitoring and alert investigation
- **Ubuntu 24.04.5 LTS** — Monitored endpoint
- **Oracle VirtualBox** — Virtual lab environment
- **MITRE ATT&CK** — Security technique mapping

## Outcomes
- Successfully generated and investigated three security-related events.
- Observed Wazuh alerts for user creation, privileged activity, and file integrity changes.
- Practised endpoint monitoring, event analysis, and SOC investigation documentation.

## Key Skills
- SIEM Monitoring
- Linux Administration
- Alert Investigation
- File Integrity Monitoring (FIM)
- MITRE ATT&CK Mapping
- Incident Documentation
